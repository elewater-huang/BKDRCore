Use the x86 BKDRCore.dll from the Actions artifact and place it alongside the examples. Close competing serial applications before connecting. Verify output OFF independently before testing. Stop polling and press the panel decimal key to restore local control; disconnecting USB does not release RMT. Only enable macros from trusted sources.

使用 x86 DLL，放在範例所在目錄。不要同時占用 COM Port。測試前確認輸出關閉，停止輪詢後按面板小數點鍵解除 RMT。
